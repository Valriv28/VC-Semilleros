## Requisitos de Instalacion
 - .NET SDK
 - Visual Studio 2022 o superior / Visual Studio Code
 - Git
## Instalación y ejecución


1. Clonar el repositorio:

   ```bash
   git clone https://github.com/Valriv28/VC-Semilleros
   ```
2. Ingresar a la carpeta del frontend:

   ```bash
   cd Front
   ```

3. Restaurar las dependencias del proyecto:

   ```bash
   dotnet restore
   ```

### Cómo ejecutarlo

1. Desde la carpeta `Front`, ejecutar el siguiente comando:

   ```bash
   dotnet run
   ```

2. Esperar a que la aplicación inicie correctamente.

3. Abrir en el navegador la dirección local que aparece en la terminal
