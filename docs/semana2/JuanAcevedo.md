## Mis historias de usuario

> Entre 5 y 7 historias en formato "como [rol] quiero [acción] para [beneficio]", pensadas desde distintos roles o necesidades del producto que el equipo está diseñando. Si escribes menos de 7, borra las líneas que no uses (mínimo 5).

**Componente:** C02 - Catálogo de logros y servicio de emisión

1. Como Administrador institucional quiero registrar un semillero asociado a mi institución para habilitarlo como contexto gobernado para futuras certificaciones.
2. Como Administrador institucional quiero activar o inactivar un semillero para controlar si puede originar nuevas certificaciones.
3. Como Responsable de semillero quiero crear un periodo de certificación para un semillero activo para delimitar temporalmente la asistencia que será evaluada.
4. Como Responsable de semillero quiero registrar participantes en un periodo para establecer quiénes pueden acumular evidencia de asistencia.
5. Como Responsable de semillero quiero registrar la asistencia de un participante a las sesiones o actividades del periodo para conservar evidencia verificable para evaluar posteriormente el criterio.
6. Como Administrador institucional quiero definir y versionar el criterio de certificación de asistencia para establecer previamente la regla con la que se decidirá la elegibilidad.
7. Como Responsable de semillero quiero evaluar la evidencia de asistencia de un participante contra el criterio vigente para determinar de forma reproducible si cumple o no cumple.
8. Como Emisor autorizado quiero declarar elegible para emisión a un participante que cumple el criterio para separar explícitamente la decisión de elegibilidad del registro de asistencia.
9. Como Emisor autorizado quiero autorizar y solicitar la emisión de la credencial para un participante elegible para iniciar una emisión gobernada y trazable.
10. Como Emisor autorizado quiero confirmar la emisión después de recibir la credencial firmada y registrar su referencia de auditoría para cerrar el proceso sin confundir la VC con la evidencia de asistencia o elegibilidad.
